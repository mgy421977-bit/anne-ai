## Summary

ANNE is an experimental cognitive architecture and **AGI candidate concept** exploring a path toward general-purpose intelligence.

**ANNE is not presented as a completed AGI system.**

ANNE is **not** defined as an energy-sector AI. Domain applications (including Vitavolt / VITA stacks) are separate layers. See [docs/applications/VITAVOLT-VITA.md](docs/applications/VITAVOLT-VITA.md).
