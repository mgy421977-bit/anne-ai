# Vitavolt / VITA — application boundary

This page defines **boundaries only**. It does not implement VITA.

| Layer | Role |
|-------|------|
| **ANNE AI** | General cognitive / reasoning architecture research |
| **VITA Intelligence** | Decision / user-facing intelligence layer |
| **VITA Engine** | Engineering computation / domain execution |
| **Vitavolt Global** | Real-world engineering and business application |

## Rules

1. Energy and industrial workflows are **application domains**, not the definition of ANNE.
2. VITA may consume ANNE outputs; **ANNE must not require VITA** to function as a research platform.
3. No claim is made here that a production VITA↔ANNE adapter exists on `main`.
4. Commercial prices, BOM lines, and engineered designs require domain systems and human responsibility—not ANNE alone.
