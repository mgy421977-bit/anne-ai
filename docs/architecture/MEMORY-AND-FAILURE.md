# Memory and failure traces

## Memory

FractalMemory stores structural traces (hypotheses, decisions, rules, empathy maps, scale events, failure traces).

**Invariant:** presence in memory does **not** mean independently verified truth. Evidence-required paths must still respect EvidenceGate.

## Failure traces

Structured failure traces (SFT) support diagnosis and bounded recovery. Recording a failure is **failure-aware infrastructure**, not automatic “learning success.”

## TARGET

Next-cycle use of failure traces under explicit budgets (no unbounded retry amplification).
