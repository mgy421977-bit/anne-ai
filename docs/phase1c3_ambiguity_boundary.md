# Phase 1c.3 — Ambiguity Boundary

ANNE treats ambiguity as a specification problem, not as a truth or confidence score.

- **LOW** ambiguity: continue the bounded cognitive path.
- **MEDIUM** ambiguity: request clarification before a bounded decision.
- **HIGH** ambiguity: abstain rather than infer missing intent.

This boundary does not grant authority, override FailFast, replace evidence enforcement,
or convert confidence into truth. Authority remains governed by the existing Agency Gate.

## Status

**EXPERIMENTAL / IMPLEMENTED:** deterministic ambiguity classification and decision boundary.

**ROADMAP:** natural-language clarification generation and richer ambiguity detection.
