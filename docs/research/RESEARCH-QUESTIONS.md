# Open research questions

1. Does an explicit cognitive loop improve reliability versus raw LLM pass-through on fixed task families?
2. When does structure reuse reduce inference cost without harming accuracy?
3. How should UNVERIFIED candidate evidence be prevented from becoming authoritative decisions across all entry points?
4. What is the right split between heuristic ANLA gating and independent verification?
5. How should dual agency mechanisms (policy gate vs human-approval gate) form one runtime path?
6. Can abstention rates be calibrated (false reject vs false accept) without domain-specific hacks?
7. How far can the architecture remain provider-neutral for both models and search?

Negative results are first-class outcomes.
