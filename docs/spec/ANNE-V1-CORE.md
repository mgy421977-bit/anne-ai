# ANNE V1.0 Core (target specification)

**Type:** target specification  
**Not:** a certificate that `main` is V1.0-complete

## Core loop (target)

FAILFAST → DUY → BAK → AMBIGUITY → GÖR → MITOS → SELECT → ANLA → EVIDENCE → INDEPENDENT VERIFICATION → HİSSET → AGENCY GATE → YAP|ABSTAIN → MEMORY → FAILURE TRACE → bounded NEXT CYCLE

## Core rules

- MITOS outputs are proposals / candidates (typically unverified).
- Evidence required ⇒ block authoritative decisions on missing/unverified/conflicting status.
- Agency is fail-closed by default for external side effects.
- Providers (model and search) are swappable; core logic should not hard-require a single vendor LLM.
