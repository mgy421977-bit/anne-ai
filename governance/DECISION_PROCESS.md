# Decision Process

Major architectural or research direction changes follow this process:

1. **Proposal** — Written in `research/decision_logs/` with clear motivation, alternatives considered, and expected impact.
2. **Review** — Open for critique (issues or discussion).
3. **Decision** — Recorded with rationale and date.
4. **Implementation** — Changes land via pull request with tests and documentation updates.

This process itself may evolve; any change to the process is also logged.
